## 🚀 Getting Started

### Prerequisites
- A modern web browser
- Basic understanding of HTML/CSS/JavaScript (for customization)

### Local Development
1. Clone or download the project files
2. Open any HTML file in your web browser
3. For local development server (optional):
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   ```

### GitHub Pages Deployment
1. Create a new repository on GitHub
2. Upload all project files to the repository
3. Go to Settings → Pages
4. Select "Deploy from a branch" and choose "main"
5. Your site will be available at `https://yourusername.github.io/repository-name`

## 🔧 Customization

### Updating Firm Information
1. **Contact Details**: Update in all HTML files where contact information appears
2. **Services**: Modify service descriptions in `services.html`
3. **Team Members**: Update leadership section in `about.html`

### Styling Changes
1. **Colors**: Update CSS custom properties in `custom.css`
2. **Fonts**: Modify font families in Tailwind configuration
3. **Layout**: Adjust grid and flexbox classes in HTML files

### Adding New Pages
1. Create new HTML file following existing structure
2. Update navigation menus in all existing files
3. Add appropriate meta tags and SEO elements
