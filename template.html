Template Page

This is a template showing how to use the component system.

How to Use Components:

  1. Add <div id="header-placeholder"></div> where you want the navigation
  2. Add <div id="footer-placeholder"></div> where you want the footer
  3. Include the JavaScript file: <script src="./js/main.js"></script>
  4. The components will load automatically!

Note: To edit the header or footer, just modify the files in the /components/ folder, and all pages will update automatically!
